# 🍠 YAM — You And Me

Application web (PWA) en test, conçue pour un nombre limité de testeurs. Ce dépôt est public uniquement pour permettre l'hébergement gratuit sur GitHub Pages ; il n'est pas destiné à être réutilisé.

- Application statique (HTML, CSS, JavaScript), sans framework ni étape de compilation.
- Services en ligne gérés à part (authentification, base de données, stockage, temps réel). Aucun code serveur ni aucune donnée n'est dans ce dépôt.
